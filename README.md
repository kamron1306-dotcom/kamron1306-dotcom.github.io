# Портфолио сайтини ишга тушириш (GitHub Pages, бепул)

Бу сайт оддий статик файллардан иборат. Сервер керак эмас. Ҳамма қадам 30–40 дақиқа олади.

## 1. Сайтни GitHub'га жойлаш

1. https://github.com да рўйхатдан ўтинг. Юзернейм танлаш муҳим: у манзилда кўринади (`USERNAME`).
2. Тепадаги **+ → New repository** ни босинг.
3. Репозиторий номи **аниқ шундай бўлиши керак**: `USERNAME.github.io` (USERNAME ўрнига ўз юзернеймингиз). **Public** ни танланг, **Create repository** ни босинг.
4. **uploading an existing file** ҳаволасини босинг. Архивни очиб, ичидаги **ҳамма файл ва `assets` папкасини** саҳифага тортиб ташланг. Пастдаги **Commit changes** ни босинг.
5. **Settings → Pages**: Source: **Deploy from a branch**, Branch: **main**, папка: **/ (root)** → **Save**.
6. 1–2 дақиқадан сўнг сайт `https://USERNAME.github.io/` манзилида очилади.

## 2. USERNAME ни алмаштириш (бир марта)

Қуйидаги файлларда `USERNAME` сўзи турибди. GitHub'да файлни очиб, қалам (Edit) тугмасини босинг, `USERNAME` ни ўз юзернеймингизга алмаштириб, **Commit changes** ни босинг:

- `index.html` (5 жойда: canonical, og:url, og:image, JSON-LD ичида url ва sameAs)
- `sitemap.xml` (1 жойда)
- `robots.txt` (1 жойда)

Шу `index.html` ичида сарлавҳа (`<title>`), тавсиф (`description`), `og:title`, `og:description` ва JSON-LD'даги исм ҳам турибди. Уларни ҳам ўз исмингиз билан алмаштиринг. Одамлар кўпинча лотинда қидиради, шунинг учун исмингиз лотинда ҳам бўлсин.

`assets/og.png` Telegram ва бошқа жойда ҳавола билан бирга чиқадиган расм. Уни ўз расмингиз билан алмаштириш мумкин (1200×630).

## 3. Таҳрирлаш режими

Матн, лойиҳа, расм, сертификат қўшиш ва ўзгартириш учун код ёзиш шарт эмас.

**Токен яратиш (бир марта):**
1. GitHub → ўнг тепада профиль расми → **Settings** → пастда **Developer settings** → **Personal access tokens → Fine-grained tokens → Generate new token**.
2. Номи: `portfolio`. Муддати: 90 кун ёки кўпроқ.
3. **Repository access → Only select repositories** → фақат `USERNAME.github.io` ни танланг.
4. **Permissions → Repository permissions → Contents: Read and write**.
5. **Generate token** ни босиб, чиққан `github_pat_...` матнини нусхалаб олинг. У бир марта кўрсатилади.

**Кириш:** `https://USERNAME.github.io/#admin` манзилини очинг, репозиторий (`USERNAME/USERNAME.github.io`) ва токенни киритинг.

Ўнг томонда таҳрирлаш панели чиқади. Ўзгартирганингиз саҳифада дарҳол кўринади. Охирида **Сақлаш** ни босинг: сайт 1–2 дақиқада янгиланади. Расмлар юклаш тугмаси билан қўшилади.

Хавфсизлик: токенни ҳеч кимга берманг ва чатларга ташламанг. «Эслаб қол» ни фақат ўз қурилмангизда белгиланг. Токен йўқолса, GitHub'да ўчириб, янгисини яратинг. Токен фақат шу битта репозиторийга ёзиш рухсатига эга.

## 4. Алоқа формаси (хабарлар почтангизга келади)

1. https://web3forms.com га киринг, почтангизни ёзиб **Access Key** олинг (калит почтангизга келади).
2. Таҳрирлаш режими → **Уланишлар** → **Web3Forms Access Key** га ёпиштиринг → **Сақлаш**.

Калит киритилмагунча форма сайтда кўринмайди. Хабарлар сиз кўрсатган почтага келади. Бепул тарифда ойига чекланган сондаги хабар бор.

## 5. Изоҳлар (Supabase)

1. https://supabase.com да рўйхатдан ўтиб **New project** яратинг.
2. **SQL Editor** ни очинг, `supabase.sql` файлидаги матнни бутунлигича ёпиштириб, **Run** ни босинг.
3. **Project Settings → API** бўлимидан **Project URL** ва **anon (publishable)** калитни олинг.
4. Таҳрирлаш режими → **Уланишлар** га иккаласини киритиб, **Сақлаш** ни босинг.

**Муҳим:** `service_role` калитини ҳеч қачон сайтга қўйманг. Фақат `anon` ёки `publishable` калит керак. Supabase менюларининг номлари вақт ўтиши билан ўзгариши мумкин.

**Тасдиқлаш:** ҳар бир янги изоҳ «тасдиқланмаган» бўлиб тушади ва сайтда кўринмайди. Supabase → **Table Editor → comments** да керакли қаторда `approved` ни `true` қилсангиз, у чиқади. Ножўя изоҳни қаторни ўчириб олиб ташлайсиз. Агар Web3Forms ҳам уланган бўлса, ҳар янги изоҳ ҳақида почтангизга хабар келади.

## 6. Қидирувда чиқиши

1. **Google Search Console** (search.google.com/search-console): **URL prefix** → `https://USERNAME.github.io/`. Тасдиқлаш учун «HTML tag» усулини танланг: берилган `<meta name="google-site-verification" ...>` қаторини `index.html` ичида `<head>` га қўшинг. Кейин **Sitemaps** бўлимига `sitemap.xml` ни юборинг, **URL inspection** орқали **Request indexing** ни босинг.
2. Худди шундай **Yandex Webmaster** (webmaster.yandex.com) ва **Bing Webmaster Tools** га қўшинг.
3. Инстаграм, GitHub ва Telegram профилингизга сайт ҳаволасини қўйинг. Бундай ҳаволалар қидирув тизимига сайтни тезроқ топишга ёрдам беради.

Индекслаш бир неча кундан бир неча ҳафтагача давом этади. Исмингиз бўйича қайси ўринда чиқиши рақобатга боғлиқ, буни олдиндан айтиб бўлмайди.

## 7. Кейин ўз доменингиз

Домен олганингиздан кейин: **Settings → Pages → Custom domain** га ёзинг ва регистраторда GitHub кўрсатган DNS ёзувларини қўшинг. Шундан кейин `index.html`, `sitemap.xml` ва `robots.txt` даги манзилларни янги домен билан алмаштиринг ва Search Console'га янги сайтни қўшинг.

## Файллар

- `index.html`: саҳифа ва қидирув учун мета-тегларга эга бош файл
- `content.js`: сайтдаги ҳамма матн ва рўйхатлар (таҳрирлаш режими шуни ўзгартиради)
- `app.js`, `style.css`: сайтнинг иши ва кўриниши
- `admin.js`: таҳрирлаш режими (фақат `#admin` очилганда юкланади)
- `supabase.sql`: изоҳлар жадвали
- `assets/`: расмлар
